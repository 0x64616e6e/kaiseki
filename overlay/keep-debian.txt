# Files Omarchy's package scriptlets overwrite with Arch-specific content, which must stay Debian's.
# packages/pkgbuild2deb saves each one before running an upstream scriptlet and puts it back after.
/etc/os-release              ID=omarchy ID_LIKE=arch would mislead apt tooling and third-party installers
/etc/nsswitch.conf           Arch's module list; Debian packages (libnss-*) maintain this file themselves
/etc/cups/cups-files.conf    names Arch's cups ids; Debian's CUPS uses lp and lpadmin (also left out of the package: omit.txt)
